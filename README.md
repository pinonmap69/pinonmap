# Pin on Map

A React Native Expo travel app for pinning your favorite places on the map.

## Features

- Splash screen with animated logo
- Welcome / onboarding screen
- Login, Register, Forgot Password screens
- Home dashboard with quick access cards
- Explore, Map, Statistics screens (coming soon)
- Profile with stats and achievements
- Premium subscription screen
- Settings with dark mode, notifications, language
- Terms of Service & Privacy Policy

## Tech Stack

- React Native (Expo SDK 51)
- React Navigation
- lucide-react-native icons
- TypeScript

## Getting Started

```bash
npm install
npx expo start
```
